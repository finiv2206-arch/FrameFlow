# Вимоги до проєкту FrameFlow (Онлайн-галерея фотографій)

## 1. Призначення
Веб-застосунок для завантаження, організації за альбомами та тегами, перегляду й пошуку фотографій.

## 2. Ролі користувачів
- Гість — перегляд публічних альбомів і фотографій, пошук та фільтрація за тегами.
- Зареєстрований користувач — створення і редагування власних альбомів, завантаження фотографій, додавання тегів.
- Адміністратор — модерація контенту, видалення фотографій та альбомів, керування тегами.

## 3. Сутності предметної області
| Сутність | Атрибути |
| :--- | :--- |
| User | id, username, email, password_hash, role, created_at |
| Album | id, user_id, title, description, is_public, created_at |
| Photo | id, album_id, title, image_url, uploaded_at |
| Tag | id, name, slug |
| PhotoTag | id, photo_id, tag_id |

## 4. Зв'язки
User 1 — ∞ Album; Album 1 — ∞ Photo; Photo ∞ — ∞ Tag (через проміжну таблицю PhotoTag)

## 5. Сторінки
1. `/` — головна: банер, популярні альбоми та останні додані фотографії
2. `/gallery` — загальний перелік фотографій: фільтрація за альбомами, тегами та пошук
3. `/photo/:id` — картка фотографії: повнорозмірне зображення, опис, автор, теги
4. `/upload` — форма створення альбому та завантаження нової фотографії з валідацією
5. `/profile` — особистий кабінет користувача зі списком його альбомів

## 6. Функціональні вимоги
F1. Фотографії та альбоми завантажуються асинхронно з сервера.
F2. Фільтрація фотографій за тегами та пошук працюють без перезавантаження сторінки.
F3. Форма завантаження фото перевіряє обов'язковість назви, вибір альбому, формат і розмір файлу.

## 7. Нефункціональні вимоги
N1. Адаптивність інтерфейсу від ширини екрана 360 px.
N2. Показник Lighthouse Performance ≥ 85.
