# REST API проєкту FrameFlow

Базова адреса: `http://localhost:3000/api`

| # | Ресурс | Метод | Призначення | Успіх | Помилки |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | `/albums` | GET | перелік публічних альбомів | 200 | 500 |
| 2 | `/albums/:id` | GET | детальна інформація про альбом | 200 | 404 |
| 3 | `/albums` | POST | створення нового альбому | 201 | 401, 422 |
| 4 | `/albums/:id/photos` | GET | перелік фотографій конкретного альбому | 200 | 404 |
| 5 | `/photos` | GET | загальний перелік фотографій із фільтрацією | 200 | 400 |
| 6 | `/photos/:id` | GET | картка окремої фотографії | 200 | 404 |
| 7 | `/photos` | POST | завантаження нової фотографії | 201 | 401, 422 |
| 8 | `/photos/:id` | PUT | редагування назви, опису або тегів фото | 200 | 401, 404, 422 |
| 9 | `/photos/:id` | DELETE | видалення фотографії | 204 | 401, 404 |
| 10 | `/tags` | GET | перелік усіх доступних тегів | 200 | 500 |

## Параметри GET /photos
| Параметр | Тип | Приклад | Опис |
| :--- | :--- | :--- | :--- |
| `album` | int | `?album=2` | фільтр за ідентифікатором альбому |
| `tag` | string | `?tag=nature` | фільтр за тегом (slug) |
| `q` | string | `?q=захід` | пошук за назвою фотографії |
| `sort` | enum | `?sort=newest` | сортування (`newest`, `oldest`, `popular`) |
| `page` | int | `?page=1` | номер сторінки пагінації |
